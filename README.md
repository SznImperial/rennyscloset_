# Renny's Closet

A high-end, minimalist e-commerce frontend built for **Renny's Closet**. Designed with modern aesthetics, clean lines, and an elegant editorial style that reflects the brand's identity.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Language**: TypeScript

## Features

- **Responsive Design**: Flawlessly adapts to mobile, tablet, and desktop screens.
- **Dynamic Routing**: Single-page application structure seamlessly transitioning between Home, Collection, About, and Contact pages.
- **Smooth Animations**: Elegant page transitions and scroll animations using Framer Motion.
- **Modern UI/UX**: Premium aesthetic with custom typography, clean layouts, and high-quality imagery.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Building for Production

To create a production-ready build, run:
```bash
npm run build
```
This will compile and optimize the assets into the `dist` directory.
